# Suivi des factures fournisseurs — interface

Interface web statique (JavaScript natif, aucune dépendance). Elle ne contient que l'URL du projet Supabase et sa clé **publique** : toutes les données sont protégées par la connexion et les règles d'accès côté Supabase. Aucune donnée ni aucun secret dans ce dépôt.
